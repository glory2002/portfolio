TH Academy

Designed a mobile-first LMS used by beauty educators to manage students, track progress, and deliver certifications — replacing fragmented tools and manual workflows.

TH Academy is a mobile-first learning platform for PMU training, designed to scale a hands-on teaching model into a structured digital experience. I led UX/UI and product definition, focusing on learning progression, feedback loops, and instructor efficiency across a PWA ecosystem.

  • Delivery Progressive Web App (PWA)
  • Client Tanya Hristova — PMU Expert
  • My role UX/UI design + build
  • Year 2026
  • Tools Figma · Cursor

Information architecture

Flows and user stories

The product is built around four interconnected UX flows. Below are two key flows that demonstrate how the system works end-to-end.

Flow 1 · Invite & enroll student

“As an administrator and instructor, I want to add a new student and enroll them in one or more courses by entering their details and which courses they should take, so that the system can create the student profile, enroll them in the selected courses, and send an email invitation without requiring any actions outside the platform.”

Flow 2 · Course creation

“As an instructor, I want to create and structure a course by defining its content, levels, and assignments, so that I can deliver a clear learning experience and provide meaningful feedback to students.”

Modular foundation

What I learned

Systems UX: interlocking states, not pages. Level status model = linchpin.

Three-panel layout = density vs. calm. Many passes to feel right in real study sessions.

Tech literacy helped: realtime, RLS, schema ↔ UI.
