Modernizing a Legacy
Insurance Platform

Role UI Design · CSS
Company TINQIN
Industry Insurance
Tools Figma · CSS
Year 2025

Redesigning a decade-old enterprise insurance system — improving visual hierarchy, usability, and consistency without touching the underlying architecture.

A UI modernization project for a 10-year-old enterprise insurance platform used daily by insurance agents across France. The goal was to bring the interface up to modern standards — improving visual clarity, consistency, and usability without restructuring the existing system or workflows.

Delivery Web-based · browser-only
Architecture Multi-tenant · projects & versions
Access Role-based · admin · assignee
Model Subscription · enterprise SaaS

Challenges & Constraints

Architecture

No structural changes

The existing system architecture had to remain completely untouched.

Workflows

Familiar patterns preserved

Existing user workflows had to remain intact — no relearning for agents.

Implementation

CSS only

All visual improvements through CSS — no HTML restructuring.

A product that finally got its own logo

Configuration Studio had always relied on the TINQIN corporate logo — there was no dedicated product identity. As part of this project I designed a logo for it, keeping the same geometric language and weight as the company mark.

Design system & components

I designed the full system in Figma — typography, colour tokens, form elements, accordions, cards, tables, and tree components — then implemented it directly in CSS in close collaboration with the front-end team.

Design through implementation

The design process didn't stop at handoff — I implemented the visual layer directly in CSS, working alongside the front-end team in the codebase.

Fewer handoff gaps, faster iteration, and consistent results across every state.

Reflection

Working within an unchangeable HTML structure forced me to focus entirely on the visual layer — typography, colour, spacing. Defining the design system upfront made implementation fast and consistent. Enterprise users have strong mental models — the goal wasn't to reinvent interactions, but to make everything feel dramatically cleaner.
